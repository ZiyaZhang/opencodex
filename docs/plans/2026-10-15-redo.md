# OpenCodex 重做实施计划

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 opencodex 重做成"发现 Codex 新功能 → 对照 DSH 写差距报告 → 一键开创造模式会话实现"的 DSH 插件，不再做自动验收和安装。

**Architecture:** Host 里三个确定性采集器（openai/codex release 与文件 diff、ChatGPT.app 的 asar 与 i18n diff、官方 RSS）产出候选 JSON；一个本地 DSH 索引（包 README 摘要、config catalog、agent notes）供检索；Flash 一次调用做归类，V4-Pro 在一个带证据目录的分析会话里按固定模板写报告，Host 用确定性规则校验引用；人勾选后 Host 用 `cordis` 预设新建会话交接。状态只有候选四态，存储全是明文 JSON 和 Markdown。

**Tech Stack:** TypeScript、Node 24、DSH 0.2.1-alpha.2 公开包（`@deepseek-ai/dsh-*`）、Cordis 4.0.5-alpha.1、esbuild、`node --test`（经 tsx）、`gh` CLI、`plutil`、客户端 React 18 加 `marked` 与 `dompurify`。

```ts
import { check } from './check.js';

export const SOURCES = ['codex-release', 'codex-files', 'desktop', 'rss'] as const;
export type Source = typeof SOURCES[number];
export const STATUSES = ['new', 'reported', 'started', 'ignored'] as const;
export type Status = typeof STATUSES[number];
export type EvidenceKind = 'pr' | 'file' | 'chunk' | 'i18n' | 'rss' | 'feature-flag' | 'schema' | 'doc';

export interface Evidence { kind: EvidenceKind; ref: string; url?: string; excerpt?: string }
export interface Classification { category: 'cli-core' | 'desktop' | 'cloud' | 'model' | 'fix' | 'other'; relevance: 'high' | 'medium' | 'low'; mergedInto?: string; rationale: string }
export interface ReportRecord { path: string; sessionId?: string; generatedAt: string; checks: { requiredSections: boolean; dshRefsTotal: number; dshRefsResolved: number } }
export interface Candidate {
  id: string; fingerprint: string; source: Source; title: string; summary: string;
  status: Status; createdAt: string; updatedAt: string;
  window?: { fromTag?: string; toTag?: string; version?: string };
  evidence: Evidence[];
  classification?: Classification;
  report?: ReportRecord;
  started?: { sessionId: string; at: string };
}

const TRANSITIONS: Record<Status, readonly Status[]> = {
  new: ['reported', 'ignored'], reported: ['started', 'ignored', 'reported'], started: ['ignored'], ignored: ['new'],
};
export function fingerprintOf(source: Source, key: string): string {
  check(key.trim().length > 0 && !key.includes('\n'), 'fingerprint key must be one line');
  return `${source}:${key}`;
}
export function transition(candidate: Candidate, status: Status, at: string): Candidate {
  check(TRANSITIONS[candidate.status].includes(status), `Invalid transition ${candidate.status} -> ${status}`);
  return { ...candidate, status, updatedAt: at };
}
```

`reported -> reported` 允许重新生成报告；`ignored -> new` 允许人工恢复。

```ts
import { mkdir, open, readFile, readdir, rename, unlink } from 'node:fs/promises';
import { randomUUID } from 'node:crypto';
import { dirname, join } from 'node:path';
import { fingerprintOf, transition, type Candidate, type Evidence, type Source, type Status } from './candidate.js';
import { check } from './check.js';

export interface UpsertInput { source: Source; key: string; title: string; summary: string; evidence: Evidence[]; window?: Candidate['window'] }
export type Checkpoints = Record<string, string | undefined>;

export async function writeJsonAtomic(path: string, value: unknown): Promise<void> {
  await mkdir(dirname(path), { recursive: true, mode: 0o700 });
  const temp = `${path}.${randomUUID()}.tmp`;
  const handle = await open(temp, 'wx', 0o600);
  try { await handle.writeFile(`${JSON.stringify(value, null, 2)}\n`, 'utf8'); await handle.sync(); } finally { await handle.close(); }
  try { await rename(temp, path); } catch (error) { await unlink(temp).catch(() => undefined); throw error; }
}

/** One directory, one JSON file per candidate, one state.json for checkpoints. No locks: one Host owns the directory. */
export class CandidateStore {
  private queue: Promise<unknown> = Promise.resolve();
  constructor(readonly directory: string, private readonly now: () => Date = () => new Date()) {}
  private get candidatesDir() { return join(this.directory, 'candidates'); }
  private serial<T>(work: () => Promise<T>): Promise<T> {
    const next = this.queue.then(work, work);
    this.queue = next.catch(() => undefined);
    return next;
  }
  async list(filter: { status?: Status; source?: Source } = {}): Promise<Candidate[]> {
    await mkdir(this.candidatesDir, { recursive: true, mode: 0o700 });
    const files = (await readdir(this.candidatesDir)).filter(name => name.endsWith('.json'));
    const items = await Promise.all(files.map(async name => JSON.parse(await readFile(join(this.candidatesDir, name), 'utf8')) as Candidate));
    return items.filter(c => (!filter.status || c.status === filter.status) && (!filter.source || c.source === filter.source))
      .sort((a, b) => b.updatedAt.localeCompare(a.updatedAt));
  }
  async get(id: string): Promise<Candidate> {
    check(/^[0-9a-f-]{36}$/.test(id), 'candidate id must be a UUID');
    return JSON.parse(await readFile(join(this.candidatesDir, `${id}.json`), 'utf8')) as Candidate;
  }
  async findByFingerprint(fingerprint: string): Promise<Candidate | undefined> {
    return (await this.list()).find(c => c.fingerprint === fingerprint);
  }
  /** Insert or refresh by fingerprint; `created` lets collectors count genuinely new candidates. */
  upsert(input: UpsertInput): Promise<{ candidate: Candidate; created: boolean }> {
    return this.serial(async () => {
      const fingerprint = fingerprintOf(input.source, input.key);
      const at = this.now().toISOString();
      const existing = await this.findByFingerprint(fingerprint);
      const candidate: Candidate = existing
        ? { ...existing, title: input.title, summary: input.summary, evidence: input.evidence, window: input.window ?? existing.window, updatedAt: at }
        : { id: randomUUID(), fingerprint, source: input.source, title: input.title, summary: input.summary, evidence: input.evidence, window: input.window, status: 'new', createdAt: at, updatedAt: at };
      await this.save(candidate);
      return { candidate, created: !existing };
    });
  }
  transition(id: string, status: Status): Promise<Candidate> {
    return this.serial(async () => { const next = transition(await this.get(id), status, this.now().toISOString()); await this.save(next); return next; });
  }
  patch(id: string, update: (candidate: Candidate) => Candidate): Promise<Candidate> {
    return this.serial(async () => { const next = { ...update(await this.get(id)), updatedAt: this.now().toISOString() }; await this.save(next); return next; });
  }
  async checkpoint(name: string): Promise<string | undefined> { return (await this.readState())[name]; }
  async checkpoints(): Promise<Checkpoints> { return this.readState(); }
  setCheckpoint(name: string, value: string): Promise<void> {
    return this.serial(async () => { const state = await this.readState(); state[name] = value; await writeJsonAtomic(join(this.directory, 'state.json'), state); });
  }
  private async readState(): Promise<Checkpoints> {
    try { return JSON.parse(await readFile(join(this.directory, 'state.json'), 'utf8')) as Checkpoints; }
    catch (error) { if ((error as NodeJS.ErrnoException).code === 'ENOENT') return {}; throw error; }
  }
  private async save(candidate: Candidate): Promise<void> {
    await mkdir(this.candidatesDir, { recursive: true, mode: 0o700 });
    await writeJsonAtomic(join(this.candidatesDir, `${candidate.id}.json`), candidate);
  }
}
```

```ts
import { promisify } from 'node:util';
import { publicNetwork } from './public-network.js';

export type GhRunner = (args: string[], signal?: AbortSignal) => Promise<string>;
export interface Release { tag: string; publishedAt: string; body: string }
export interface PullRequest { number: number; title: string; body: string; url: string; additions: number; deletions: number; files: Array<{ path: string; additions: number; deletions: number }> }

const REPO = 'openai/codex';
export const defaultGhRunner: GhRunner = async (args, signal) => {
  const { stdout } = await promisify(execFile)('gh', args, { signal, maxBuffer: 64 * 1024 * 1024, env: { ...process.env, GH_PAGER: 'cat' } });
  return stdout;
};

export class GitHubClient {
  private readonly gh?: GhRunner;
  private readonly fetchImpl?: typeof fetch;
  /** `gh: null` disables the CLI; `fetch` replaces the proxied network for the REST path (tests pass a stub, production leaves it unset). */
  constructor(options: { gh?: GhRunner | null; fetch?: typeof fetch } = {}) {
    this.gh = options.gh === null ? undefined : options.gh ?? defaultGhRunner;
    this.fetchImpl = options.fetch;
  }
  private async network(signal?: AbortSignal) {
    return this.fetchImpl ? { fetch: this.fetchImpl, close: async () => {} } : publicNetwork(signal ?? new AbortController().signal);
  }

  /** One page when `pages` is 1; otherwise every page as a separate element (gh: --paginate --slurp; REST: manual loop). */
  private async api(path: string, pages: number, signal?: AbortSignal): Promise<unknown[]> {
    if (this.gh) {
      const args = pages > 1 ? ['api', '--paginate', '--slurp', '-H', 'Accept: application/vnd.github+json', path] : ['api', '-H', 'Accept: application/vnd.github+json', path];
      const parsed: unknown = JSON.parse(await this.gh(args, signal));
      return pages > 1 ? parsed as unknown[] : [parsed];
    }
    const network = await this.network(signal);
    try {
      const out: unknown[] = [];
      for (let page = 1; page <= pages; page++) {
        const url = `https://api.github.com/${path}${path.includes('?') ? '&' : '?'}page=${page}`;
        const response = await network.fetch(url, { headers: { Accept: 'application/vnd.github+json', 'User-Agent': 'dsh-opencodex/0.3' }, signal });
        if (!response.ok) throw new Error(`GitHub HTTP ${response.status} for ${path}`);
        const body: unknown = await response.json();
        out.push(body);
        if (Array.isArray(body) ? body.length === 0 : !(body as { files?: unknown[] }).files?.length) break;
      }
      return out;
    } finally { await network.close(); }
  }
  async stableReleases(limit: number, signal?: AbortSignal): Promise<Release[]> {
    const [raw] = await this.api(`repos/${REPO}/releases?per_page=100`, 1, signal) as [Array<{ tag_name: string; prerelease: boolean; published_at: string; body: string | null }>];
    return raw.filter(r => !r.prerelease && /^rust-v\d+\.\d+\.\d+$/.test(r.tag_name)).slice(0, limit)
      .map(r => ({ tag: r.tag_name, publishedAt: r.published_at, body: r.body ?? '' }));
  }
  async pullRequest(number: number, signal?: AbortSignal): Promise<PullRequest> {
    const raw = this.gh
      ? JSON.parse(await this.gh(['pr', 'view', String(number), '--repo', REPO, '--json', 'number,title,body,url,additions,deletions,files'], signal))
      : (await this.api(`repos/${REPO}/pulls/${number}`, 1, signal))[0];
    const r = raw as { number: number; title: string; body: string | null; url?: string; html_url?: string; additions: number; deletions: number; files?: Array<{ path: string; additions: number; deletions: number }> };
    const files = r.files ?? (await this.api(`repos/${REPO}/pulls/${number}/files?per_page=100`, 3, signal) as Array<Array<{ filename: string; additions: number; deletions: number }>>).flat().map(f => ({ path: f.filename, additions: f.additions, deletions: f.deletions }));
    return { number: r.number, title: r.title, body: r.body ?? '', url: r.url ?? r.html_url ?? `https://github.com/${REPO}/pull/${number}`, additions: r.additions, deletions: r.deletions, files };
  }
  async pullRequestDiff(number: number, signal?: AbortSignal): Promise<string> {
    if (this.gh) return this.gh(['pr', 'diff', String(number), '--repo', REPO], signal);
    const network = await this.network(signal);
    try {
      const response = await network.fetch(`https://api.github.com/repos/${REPO}/pulls/${number}`, { headers: { Accept: 'application/vnd.github.diff', 'User-Agent': 'dsh-opencodex/0.3' }, signal });
      if (!response.ok) throw new Error(`GitHub HTTP ${response.status} for pr diff ${number}`);
      return await response.text();
    } finally { await network.close(); }
  }
  /** Blob paths and shas at one tag, restricted by a path predicate. The recursive tree of this repo is far below GitHub's 100k-entry limit; a truncated answer is an error, never a partial result. */
  async treePaths(tag: string, keep: (path: string) => boolean, signal?: AbortSignal): Promise<Map<string, string>> {
    const [raw] = await this.api(`repos/${REPO}/git/trees/${encodeURIComponent(tag)}?recursive=1`, 1, signal) as [{ truncated: boolean; tree: Array<{ path: string; type: string; sha: string }> }];
    if (raw.truncated) throw new Error(`GitHub tree for ${tag} is truncated`);
    return new Map(raw.tree.filter(e => e.type === 'blob' && keep(e.path)).map(e => [e.path, e.sha]));
  }
  /** One file's text at one tag. */
  async fileAt(tag: string, path: string, signal?: AbortSignal): Promise<string> {
    const [raw] = await this.api(`repos/${REPO}/contents/${path.split('/').map(encodeURIComponent).join('/')}?ref=${encodeURIComponent(tag)}`, 1, signal) as [{ encoding: string; content: string }];
    if (raw.encoding !== 'base64') throw new Error(`Unexpected encoding ${raw.encoding} for ${path}@${tag}`);
    return Buffer.from(raw.content, 'base64').toString('utf8');
  }
}
```

```ts
import { join } from 'node:path';
import { writeJsonAtomic, type CandidateStore } from '../../core/store.js';
import type { GitHubClient } from '../github.js';

export interface ReleaseFeature { text: string; prs: number[] }

export function parseReleaseBody(body: string): ReleaseFeature[] {
  const section = body.split(/^## /m).find(part => /^New Features/i.test(part));
  if (!section) return [];
  return section.split('\n').filter(line => /^\s*[-*]\s+/.test(line)).map(line => {
    const text = line.replace(/^\s*[-*]\s+/, '').replace(/\s*\((?:#\d+(?:,\s*)?)+\)\s*$/, '').trim();
    const prs = [...line.matchAll(/#(\d{3,7})/g)].map(m => Number(m[1]));
    return { text, prs };
  }).filter(f => f.text && f.prs.length);
}

export const minor = (tag: string): string => tag.replace(/^rust-v/, '').split('.').slice(0, 2).join('.');
export interface StableWindow { from: string; to: string; releases: string[] }
/**
 * Tags come newest first. With a checkpoint present in the list, the window runs from it to the newest tag and
 * covers every stable release in between. Without one, it starts at the newest tag whose minor differs from the latest.
 */
export function stableWindow(tags: string[], lastSeen?: string): StableWindow | undefined {
  const to = tags[0];
  if (!to || to === lastSeen) return undefined;
  const fromIndex = lastSeen && tags.includes(lastSeen) ? tags.indexOf(lastSeen) : tags.findIndex(tag => minor(tag) !== minor(to));
  if (fromIndex <= 0) return undefined;
  return { from: tags[fromIndex]!, to, releases: tags.slice(0, fromIndex) };
}

export interface ReleaseCollection { window?: StableWindow; added: number; /** The checkpoint is older than the fetched tags; intermediate releases were not collected. */ gap: boolean }
export async function collectReleases(store: CandidateStore, github: GitHubClient, snapshotDir: string, signal?: AbortSignal): Promise<ReleaseCollection> {
  const releases = await github.stableReleases(12, signal);
  const tags = releases.map(r => r.tag);
  const lastSeen = await store.checkpoint('lastStableTag');
  const gap = lastSeen !== undefined && !tags.includes(lastSeen);
  const window = stableWindow(tags, lastSeen);
  if (!window) return { added: 0, gap };
  let added = 0;
  for (const release of releases.filter(r => window.releases.includes(r.tag))) {
    await writeJsonAtomic(join(snapshotDir, 'codex-releases', `${release.tag}.json`), release);
    for (const feature of parseReleaseBody(release.body)) {
      const prs = await Promise.all(feature.prs.map(n => github.pullRequest(n, signal).catch(() => undefined)));
      const evidence = prs.flatMap((pr, i) => pr ? [{ kind: 'pr' as const, ref: `#${pr.number}`, url: pr.url, excerpt: `${pr.title}\n${pr.files.slice(0, 20).map(f => f.path).join('\n')}` }] : [{ kind: 'pr' as const, ref: `#${feature.prs[i]}` }]);
      const { created } = await store.upsert({ source: 'codex-release', key: `pr:${feature.prs[0]}`, title: feature.text.slice(0, 160), summary: feature.text, evidence, window: { fromTag: window.from, toTag: release.tag } });
      if (created) added++;
    }
  }
  await store.setCheckpoint('lastStableTag', window.to);
  return { window, added, gap };
}
```

`stableReleases(12)` 只取最近 12 个正式版；检查点比这 12 个都老时（停用一个多月），`stableWindow` 退回"上一个次版本"规则，中间的版本不补采，`gap: true` 由页面提示一句，不做自动回填。

```ts
import { join } from 'node:path';
import { writeJsonAtomic, type CandidateStore } from '../../core/store.js';
import type { EvidenceKind } from '../../core/candidate.js';
import type { GitHubClient } from '../github.js';
import { minor, type StableWindow } from './codex-releases.js';

export const WATCHED = (path: string): boolean => /^codex-rs\/features\/|^codex-rs\/app-server-protocol\/schema\/typescript\/|^docs\/[^/]+\.md$|^codex-rs\/config\.md$/.test(path);
export interface ChangedPath { path: string; status: 'added' | 'removed' | 'modified' }
export interface ChangedFile extends ChangedPath { added: string[] }
export interface FileGroup { key: string; title: string; kind: EvidenceKind; files: ChangedFile[]; excerpt: string }

export function changedWatched(before: Map<string, string>, after: Map<string, string>): ChangedPath[] {
  const paths = [...new Set([...before.keys(), ...after.keys()])].sort();
  return paths.flatMap(path => {
    const a = before.get(path), b = after.get(path);
    if (a === b) return [];
    return [{ path, status: a === undefined ? 'added' as const : b === undefined ? 'removed' as const : 'modified' as const }];
  });
}
export function addedLines(before: string, after: string): string[] {
  const old = new Set(before.split('\n'));
  return after.split('\n').filter(line => line.trim() && !old.has(line));
}
export function groupWatchedFiles(files: ChangedFile[]): FileGroup[] {
  const buckets = new Map<string, FileGroup>();
  for (const file of files.filter(f => WATCHED(f.path))) {
    const key = file.path.startsWith('codex-rs/features/') ? 'feature-flags'
```

```ts
import { Buffer } from 'node:buffer';
/** Minimal asar writer matching Electron's pickle header layout. */
export function makeAsar(files: Record<string, string>): Buffer {
  const tree: { files: Record<string, unknown> } = { files: {} };
  const chunks: Buffer[] = []; let offset = 0;
  for (const [path, text] of Object.entries(files)) {
    const data = Buffer.from(text, 'utf8');
    let node = tree; const parts = path.split('/').filter(Boolean);
    for (const dir of parts.slice(0, -1)) node = (node.files[dir] ??= { files: {} }) as typeof tree;
    node.files[parts.at(-1)!] = { size: data.length, offset: String(offset) };
    chunks.push(data); offset += data.length;
  }
  const json = Buffer.from(JSON.stringify(tree), 'utf8');
  const padded = Buffer.alloc(Math.ceil(json.length / 4) * 4); json.copy(padded);
  const header = Buffer.alloc(16);
  header.writeUInt32LE(4, 0); header.writeUInt32LE(padded.length + 8, 4); header.writeUInt32LE(padded.length + 4, 8); header.writeUInt32LE(json.length, 12);
  return Buffer.concat([header, padded, ...chunks]);
}
```

```ts
import { open } from 'node:fs/promises';

export interface AsarEntry { path: string; size: number; offset: number }
interface Node { files?: Record<string, Node>; size?: number; offset?: string; unpacked?: boolean }

async function header(path: string): Promise<{ tree: Node; base: number }> {
  const handle = await open(path, 'r');
  try {
    const prefix = Buffer.alloc(16);
    await handle.read(prefix, 0, 16, 0);
    const pickleSize = prefix.readUInt32LE(4), jsonLength = prefix.readUInt32LE(12);
    if (jsonLength > 64 * 1024 * 1024) throw new Error('asar header exceeds 64 MiB');
    const json = Buffer.alloc(jsonLength);
    await handle.read(json, 0, jsonLength, 16);
    return { tree: JSON.parse(json.toString('utf8')) as Node, base: 8 + pickleSize };
  } finally { await handle.close(); }
}
export async function listAsar(path: string): Promise<AsarEntry[]> {
  const { tree } = await header(path);
  const out: AsarEntry[] = [];
  const walk = (node: Node, prefix: string) => {
    for (const [name, child] of Object.entries(node.files ?? {})) {
      const full = `${prefix}/${name}`;
      if (child.files) walk(child, full);
      else if (!child.unpacked) out.push({ path: full, size: child.size ?? 0, offset: Number(child.offset ?? 0) });
    }
  };
  walk(tree, '');
  return out;
}
/** Pass an entry from `listAsar` when you already have the listing; the header is 5.8 MB in ChatGPT.app and parsing it twice per file adds up. */
export async function readAsarEntry(path: string, entryPath: string | AsarEntry, limit = 64 * 1024 * 1024): Promise<Buffer> {
  const { base } = await header(path);
  const entry = typeof entryPath === 'string' ? (await listAsar(path)).find(e => e.path === entryPath) : entryPath;
  if (!entry) throw new Error(`asar entry not found: ${String(entryPath)}`);
  if (entry.size > limit) throw new Error(`asar entry exceeds ${limit} bytes`);
  const handle = await open(path, 'r');
  try { const buffer = Buffer.alloc(entry.size); await handle.read(buffer, 0, entry.size, base + entry.offset); return buffer; }
  finally { await handle.close(); }
}
```

```ts
export async function collectDesktop(store: CandidateStore, snapshotDir: string, plistPath: string, locale: string): Promise<{ version: string; changed: boolean; added: number }> {
  try { await stat(plistPath); } catch { return { version: '', changed: false, added: 0 }; }
  const last = await store.checkpoint('lastDesktopVersion');

    const diff = diffManifests(previous, current);

    }
  }

  return { version: current.version, changed: true, added };
}
```

```ts
import type { CandidateStore } from '../../core/store.js';
import { parseChangelog, type ChangelogFeature } from '../changelog-parser.js';
import { publicNetwork } from '../public-network.js';

export const RSS_URL = 'https://developers.openai.com/codex/changelog/rss.xml';
export function rssCandidates(xml: string, pageUrl: string, now = new Date()): ChangelogFeature[] { return parseChangelog(xml, pageUrl, { now, maxAgeDays: 120, maxReleases: 40, maxFeatures: 120 }); }

export async function collectRss(store: CandidateStore, signal: AbortSignal, fetcher?: typeof fetch): Promise<number> {
  const network = fetcher ? { fetch: fetcher, close: async () => {} } : await publicNetwork(signal);
  try {
    const response = await network.fetch(RSS_URL, { signal, headers: { Accept: 'application/rss+xml', 'User-Agent': 'dsh-opencodex/0.3' } });
    if (!response.ok) throw new Error(`RSS HTTP ${response.status}`);
    const xml = await response.text();
    const hash = createHash('sha256').update(xml).digest('hex');
    if (await store.checkpoint('rssHash') === hash) return 0;
    let added = 0;
    for (const item of rssCandidates(xml, 'https://developers.openai.com/codex/changelog')) {

      if (created) added++;
    }
    await store.setCheckpoint('rssHash', hash);
    return added;
  } finally { await network.close(); }
}
```

```ts
export interface IndexEntry { kind: 'package' | 'config' | 'note' | 'doc'; id: string; title: string; path: string; text: string }
export interface DshIndex { builtAt: string; commit: string; mirror: string; entries: IndexEntry[] }

async function* walk(dir: string, depth: number): AsyncGenerator<string> {
  if (depth < 0) return;
  for (const name of await readdir(dir)) {
    if (name === 'node_modules' || name.startsWith('.git')) continue;
    const full = join(dir, name);
    if ((await stat(full)).isDirectory()) yield* walk(full, depth - 1); else yield full;
  }
}
function summaryOf(markdown: string): string {
  const section = markdown.split(/^## /m).find(part => /^Summary/i.test(part));
  return (section ?? markdown).replace(/^Summary\s*/i, '').split(/^## /m)[0]!.replace(/\s+/g, ' ').trim().slice(0, 1_200);
}
export async function buildDshIndex(mirror: string): Promise<DshIndex> {
  const entries: IndexEntry[] = [];
  for await (const file of walk(join(mirror, 'packages'), 4)) {
    // packages/<group>/<name>/README.md only; the directory README at packages/README.md is not a package.
    if (!file.endsWith('/README.md') || relative(mirror, file).split('/').length < 4) continue;
    const text = await readFile(file, 'utf8');
    const title = text.match(/^# (.+)$/m)?.[1]?.trim() ?? relative(mirror, file);
    entries.push({ kind: 'package', id: title, title, path: relative(mirror, file), text: summaryOf(text) });
  }
  try {
    const catalog = await readFile(join(mirror, 'docs/config-catalog.md'), 'utf8');
    for (const part of catalog.split(/^## /m).slice(1)) {
      const title = part.split('\n')[0]!.replace(/`/g, '').trim();
      entries.push({ kind: 'config', id: title, title, path: 'docs/config-catalog.md', text: part.replace(/\s+/g, ' ').slice(0, 1_500) });
    }
  } catch { /* catalog is optional */ }
  for (const status of ['implemented', 'proposed']) {
    try {
      for await (const file of walk(join(mirror, '.agents/notes', status), 2)) {
        if (!file.endsWith('.md') || file.endsWith('.zh.md') || /AGENTS|CLAUDE/.test(file)) continue;
        const text = await readFile(file, 'utf8');
        const title = text.match(/^# (.+)$/m)?.[1]?.trim() ?? relative(mirror, file);
        entries.push({ kind: 'note', id: relative(mirror, file), title: `${title} [${status}]`, path: relative(mirror, file), text: text.replace(/\s+/g, ' ').slice(0, 1_500) });
      }
    } catch { /* notes are optional */ }
  }
  let commit = 'unknown';
  try { commit = (await promisify(execFile)('git', ['-C', mirror, 'rev-parse', 'HEAD'])).stdout.trim(); } catch { /* not a git checkout */ }
  return { builtAt: new Date().toISOString(), commit, mirror, entries };
}
function tokens(query: string): string[] {
  return [...new Set(query.replace(/([a-z])([A-Z])/g, '$1 $2').toLowerCase().split(/[^a-z0-9一-鿿]+/).filter(t => t.length >= 2))];
}
export function searchIndex(index: DshIndex, query: string, limit = 5): IndexEntry[] {
  const terms = tokens(query);
  return index.entries.map(entry => {
    const title = entry.title.toLowerCase(), text = entry.text.toLowerCase();
    const score = terms.reduce((sum, term) => sum + (title.includes(term) ? 3 : 0) + (text.includes(term) ? 1 : 0), 0);
    return { entry, score };
  }).filter(x => x.score > 0).sort((a, b) => b.score - a.score).slice(0, limit).map(x => x.entry);
}
```

```ts
export async function runCheck(options: { directory: string; store: CandidateStore; settings: Settings; github?: GitHubClient; signal: AbortSignal; fetcher?: typeof fetch }): Promise<CheckResult> {
  const { directory, store, settings, signal } = options;

  const snapshots = join(directory, 'snapshots');

  await attempt('rss', async () => { result.rss = await collectRss(store, signal, options.fetcher); });
  if (settings.dshMirrorPath) await attempt('index', async () => { const index = await refreshIndex(directory, store, settings.dshMirrorPath); result.index = { entries: index.entries.length, commit: index.commit }; });

}
```

```ts
import type { GenerateOptions, StreamChunk } from '@deepseek-ai/dsh-llm';
import type { Candidate, Classification } from '../core/candidate.js';
import type { ModelRoute } from '../core/settings.js';

const CATEGORIES = new Set(['cli-core', 'desktop', 'cloud', 'model', 'fix', 'other']);
const RELEVANCE = new Set(['high', 'medium', 'low']);
const SYSTEM = `你是 DeepSeek Harness（DSH）团队的功能跟踪助手。给你一批 Codex 的更新候选，逐条判断：
- category：cli-core（Codex CLI/TUI/核心/app-server 协议）、desktop（ChatGPT.app 里的 Codex 桌面端界面）、cloud（依赖 OpenAI 云端或账号的功能）、model（模型发布与退役公告）、fix（纯修复）、other。
- relevance：对 DSH（一个本地运行的开源 agent harness，有 Web UI、插件系统、子代理、技能、hooks、沙箱、计划模式）的参考价值：high/medium/low。
- mergedInto：如果这条和同批另一条明显是同一功能，填那条的 id，否则省略。
- rationale：一句话，中文。
只输出 JSON 数组，不要解释。`;

export function parseClassification(text: string, ids: Set<string>): Map<string, Classification> {
  const json = text.replace(/^```(?:json)?\s*|\s*```$/g, '').trim();
  const out = new Map<string, Classification>();
  let parsed: unknown;
  try { parsed = JSON.parse(json); } catch { return out; }
  if (!Array.isArray(parsed)) return out;
  for (const item of parsed as Array<Record<string, unknown>>) {
    if (typeof item?.id !== 'string' || !ids.has(item.id) || !CATEGORIES.has(String(item.category)) || !RELEVANCE.has(String(item.relevance))) continue;
    out.set(item.id, { category: item.category as Classification['category'], relevance: item.relevance as Classification['relevance'], rationale: String(item.rationale ?? '').slice(0, 300), ...(typeof item.mergedInto === 'string' && ids.has(item.mergedInto) && item.mergedInto !== item.id ? { mergedInto: item.mergedInto } : {}) });
  }
  return out;
}
export async function classifyBatch(llm: { stream(options: GenerateOptions): AsyncIterable<StreamChunk> }, route: ModelRoute, candidates: Candidate[], signal: AbortSignal): Promise<Map<string, Classification>> {
  const batch = candidates.slice(0, 30);
  const user = batch.map(c => `- id: ${c.id}\n  source: ${c.source}\n  title: ${c.title}\n  summary: ${c.summary.slice(0, 600).replace(/\n/g, ' ')}`).join('\n');
  let text = '';
  for await (const chunk of llm.stream({ provider: route.provider, model: route.model, system: SYSTEM, messages: [{ role: 'user', content: [{ type: 'text', text: user }] }], temperature: 0, maxTokens: 4_000, signal } as GenerateOptions)) {
    if (chunk.type === 'text-delta') text += chunk.text;
    if (chunk.type === 'finish' && chunk.reason.kind !== 'stop') throw new Error(`classify: model finished with ${chunk.reason.kind}`);
  }
  return parseClassification(text, new Set(batch.map(c => c.id)));
}
```

```ts
import { mkdir, writeFile } from 'node:fs/promises';
import { join } from 'node:path';
import type { Candidate } from '../../core/candidate.js';
import type { IndexEntry } from '../index/dsh-index.js';

export interface DiffFile { path: string; diff: string }
const weight = (path: string) => /\/tests?\//.test(path) || /_tests?\.rs$|\.spec\.|\.test\./.test(path) ? 0 : /\.(rs|ts|tsx)$/.test(path) ? 2 : 1;
export function rankDiffFiles(files: DiffFile[], budget: number): { kept: DiffFile[]; dropped: DiffFile[] } {
  const sorted = [...files].sort((a, b) => weight(b.path) - weight(a.path) || a.diff.length - b.diff.length);
  const kept: DiffFile[] = [], dropped: DiffFile[] = []; let used = 0;
  for (const file of sorted) { if (weight(file.path) > 0 && used + file.diff.length <= budget) { kept.push(file); used += file.diff.length; } else dropped.push(file); }
  return { kept, dropped };
}
const slug = (text: string) => text.replace(/[^A-Za-z0-9._-]+/g, '-').replace(/-+/g, '-').replace(/^-|-$/g, '').slice(0, 80);
export async function buildEvidencePack(input: { directory: string; candidate: Candidate; diffs: DiffFile[]; dshHits: IndexEntry[]; budget?: number }): Promise<string> {
  const root = join(input.directory, 'evidence');
  await mkdir(join(root, 'sources'), { recursive: true, mode: 0o700 });
  await mkdir(join(root, 'dsh'), { recursive: true, mode: 0o700 });
  await writeFile(join(root, 'candidate.json'), JSON.stringify(input.candidate, null, 2));
  const lines = ['# 证据目录', '', `候选：${input.candidate.title}`, `来源：${input.candidate.source}`, '', '## sources/'];
  for (const [i, evidence] of input.candidate.evidence.entries()) {
    const name = `${slug(evidence.kind + '-' + evidence.ref)}.md`;
    await writeFile(join(root, 'sources', name), `# ${evidence.kind} ${evidence.ref}\n\n${evidence.url ?? ''}\n\n${evidence.excerpt ?? ''}\n`);
    lines.push(`- sources/${name}`); void i;
  }
  const { kept, dropped } = rankDiffFiles(input.diffs, input.budget ?? 60_000);
  for (const file of kept) { const name = `diff-${slug(file.path)}.diff`; await writeFile(join(root, 'sources', name), file.diff); lines.push(`- sources/${name}`); }
  lines.push('', '## dsh/（官方镜像索引命中，路径相对镜像根目录）');
  for (const [i, hit] of input.dshHits.entries()) {
    const name = `${String(i + 1).padStart(2, '0')}-${slug(hit.path.replace(/\.md$/, ''))}.md`;
    await writeFile(join(root, 'dsh', name), `# ${hit.title}\n\n路径：${hit.path}\n\n${hit.text}\n`);
    lines.push(`- dsh/${name} ← ${hit.path}`);
  }
  if (dropped.length) lines.push('', '## 未读文件（超出证据预算）', ...dropped.map(f => `- ${f.path}`));
  await writeFile(join(root, 'INDEX.md'), `${lines.join('\n')}\n`);
  return root;
}
```

```ts
import { randomUUID } from 'node:crypto';
import { readFile, rm, stat } from 'node:fs/promises';
import { join } from 'node:path';
import { SessionId } from '@deepseek-ai/dsh-session';
import { setSandboxMode } from '@deepseek-ai/dsh-sandbox-policy';
import type { SessionRequestId } from '@deepseek-ai/dsh-api-session-controller/types';
import type { Candidate, ReportRecord } from '../../core/candidate.js';
import type { ModelRoute } from '../../core/settings.js';
import { TEMPLATE } from './template.js';

const REQUIRED = ['## 结论', '## Codex 怎么做的', '## DSH 现在有没有', '## 差哪些扩展点', '## 分级', '## 建议'];

export async function checkReport(markdown: string, mirror: string): Promise<ReportRecord['checks']> {
  const section = markdown.split('## DSH 现在有没有')[1]?.split(/^## /m)[0] ?? '';
  const refs = [...section.matchAll(/`?((?:packages|apps|docs|\.agents)\/[\w./-]+?):(\d+)`?/g)];
  let resolved = 0;
  for (const [, path, line] of refs) {
    try {
      const full = join(mirror, path!);
      if (!(await stat(full)).isFile()) continue;
      const lines = (await readFile(full, 'utf8')).split('\n').length;
      if (Number(line) >= 1 && Number(line) <= lines) resolved++;
    } catch { /* unresolved */ }
  }
  return { requiredSections: REQUIRED.every(h => markdown.includes(h)), dshRefsTotal: refs.length, dshRefsResolved: resolved };
}

/** Structural subset of ctx so tests can pass plain objects; `rename` returns SessionRenameValue in DSH, hence `unknown`. */
export interface ReportHost {
  sessionController: {
    create(request: { cwd: string; agentPreset?: string }): Promise<{ sessionId: string }>;
    rename(request: { sessionId: string; title: string }): Promise<unknown>;
    selectModel(request: { sessionId: string; provider: string; model: string }): Promise<unknown>;
    prompt(request: { sessionId: string; requestId: SessionRequestId; mode: 'queue'; content: Array<{ type: 'text'; text: string }> }, signal: AbortSignal): Promise<unknown>;
  };
  sessions: { get(id: ReturnType<typeof SessionId>): Parameters<typeof setSandboxMode>[0] | undefined };
  agents: { get(id: ReturnType<typeof SessionId>): { status: string } | undefined };
}

/** Create one analyst session in the report directory, prompt it, wait until idle, then read and check report.md. */
export async function generateReport(host: ReportHost, input: { candidate: Candidate; reportDir: string; mirror: string; model: ModelRoute; preset?: string; signal: AbortSignal; timeoutMs?: number }): Promise<ReportRecord> {
  const { candidate, reportDir, mirror, signal } = input;
  const created = await host.sessionController.create({ cwd: reportDir, ...(input.preset ? { agentPreset: input.preset } : {}) });
  await host.sessionController.rename({ sessionId: created.sessionId, title: `OpenCodex 报告 · ${candidate.title.slice(0, 60)}` });
  await host.sessionController.selectModel({ sessionId: created.sessionId, provider: input.model.provider, model: input.model.model });
  const session = host.sessions.get(SessionId(created.sessionId));
  if (session) setSandboxMode(session, 'workspace-write');
  const template = TEMPLATE.replace('{{title}}', candidate.title).replace('{{id}}', candidate.id).replace('{{source}}', candidate.source)
    .replace('{{window}}', JSON.stringify(candidate.window ?? {})).replace('{{generatedAt}}', new Date().toISOString());
  const prompt = [
    `请为下面这条 Codex 更新候选写一份差距报告，写到当前目录的 report.md。`,
    `证据在 evidence/，先读 evidence/INDEX.md。DSH 官方镜像在 ${mirror}（只读），"DSH 现在有没有"一节必须给相对镜像根目录的 路径:行号，用 rg 和 read 自己定位。`,
    `不要改镜像，不要安装任何东西，不要访问网络。写完 report.md 后回复 REPORT_DONE 并停止。`,
    '', '模板与写作规则：', template,
  ].join('\n');
  // A rerun (reported -> reported) must not return the previous file: remove it and accept only a file written after the prompt.
  const reportPath = join(reportDir, 'report.md');
  await rm(reportPath, { force: true });
  const startedAt = Date.now();
  await host.sessionController.prompt({ sessionId: created.sessionId, requestId: randomUUID() as SessionRequestId, mode: 'queue', content: [{ type: 'text', text: prompt }] }, signal);
  // The queued prompt starts a turn asynchronously, so `whenIdle()` right after `prompt` can resolve before the turn begins.
  // Poll instead: done when a fresh report.md exists and the agent is idle; give up at the deadline.
  const deadline = startedAt + (input.timeoutMs ?? 20 * 60_000);
  for (;;) {
    signal.throwIfAborted();
    if (Date.now() > deadline) throw new Error('report session timed out');
    await new Promise(resolve => setTimeout(resolve, 3_000).unref());
    const agent = host.agents.get(SessionId(created.sessionId));
    const idle = !agent || agent.status !== 'running';
    const written = await stat(reportPath).then(s => s.isFile() && s.mtimeMs >= startedAt - 1_000, () => false);
    if (written && idle) break;
  }
  const markdown = await readFile(reportPath, 'utf8');
  return { path: reportPath, sessionId: created.sessionId, generatedAt: new Date().toISOString(), checks: await checkReport(markdown, mirror) };
}
```

`ReportHost.agents.get` 的返回类型改成 `{ status: string; whenIdle(): Promise<void> } | undefined`；`status` 字段在 `@deepseek-ai/dsh-agent` 的 `Agent` 上（v1 的 host 代码用过 `agent.status === 'running'`）。

接口核对（都对着安装的 0.2.1-alpha.2 d.ts 查过，并用 tsc 验过这段代码）：`SessionCreateRequest { workspaceId?, cwd?, sessionId?, agentPreset? }`，官方 master 的公开 Remote 请求字段没变（`reusable` 只在内部 agent 层）；`selectModel` 的请求是 `SessionSelectModelRequest extends ModelSelection`（`dsh-api-session-controller/lib/types/types.d.ts:296`，`ModelSelection` 在 91 到 95 行是 `provider`、`model`、可选 `reasoningEffort`）；`rename` 返回 `Promise<SessionRenameValue>`，所以接口里写 `Promise<unknown>`；`Agent.status` 是 `'idle' | 'running'`。`reportDir` 由调用方传绝对路径。

```ts
export async function startWork(host: Pick<ReportHost, 'sessionController'>, input: { candidate: Candidate; directory: string; preset: string; mirror: string; signal: AbortSignal }): Promise<string> {
```
