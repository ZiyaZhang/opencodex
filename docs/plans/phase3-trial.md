## 怎么读「上次检查」

页面顶部这一行只反映当前 DSH 进程里最近一次检查，例如：

```text
上次检查 10/15 08:09 没有新的正式版 发布说明 +0 仓库文件 +0 桌面端 +0 RSS +0 没有错误
```

| 部分 | 含义 |
| --- | --- |
| `10/15 08:09` | 这次检查结束的时间，本机时区 |
| `rust-v0.161.0 → rust-v0.162.1`，或「没有新的正式版」 | 这次处理的 Codex 正式版窗口 |
| `发布说明 +N`、`仓库文件 +N`、`桌面端 +N`、`RSS +N` | 四个来源各新增的候选数 |
| 「没有错误」，或「N 条错误」 | 点开看每条；行首是出错的环节：`releases`、`files`、`desktop`、`rss`、`index`、`classify`，整次检查失败是 `check` |

- DSH 每次启动后，这一行先显示「DSH 启动后还没有检查过。」，启动 60 秒后的那次检查结束才有内容；重启前的结果不保留。
- 下一次定时检查在上一次结束后 `checkIntervalHours` 小时，所以每天的时间会比前一天晚一点。
- 手动点「检查更新」会把下一次定时检查改到这次结束后再算，记在当天的「人工干预」里。
- 时间和前一天一样、没有新的检查时，先看 DSH 是否关过、电脑是否长时间睡眠，再记成问题。
- 下面「DSH 索引」一行是条数、镜像提交和建立时间。每次检查都会重建索引；提交一直不变，说明镜像本身没有更新。
